# PROJECT VISION

This system is an AI-assisted engineering layer for the Rutex AI Receptionist platform.

CORE GOAL:

Understand the full codebase, detect improvements, and safely execute changes that increase system reliability and revenue conversion.

WHAT IT MUST DO:

- Read and understand entire repository structure

- Detect architectural problems and bugs

- Prioritize improvements based on impact

- Generate step-by-step execution plans

- Safely modify code without breaking existing flows

PRINCIPLE:

Never randomly change code. Every change must improve system stability or business performance.
